## 一、应用用途与用户选择

知言是可在手机上使用的聊天回复辅助工具，提供消息分析、截图识字及候选回复。它不代替用户发送微信消息，不读取微信私有数据库，不订阅微信无障碍事件，也不会读取微信聊天控件树。部分功能需要用户主动打开系统授权；拒绝非必要权限不影响本应用的其他基本设置功能。它不能保证被第三方聊天平台认可或免于风控。

## 二、处理哪些信息、为什么处理

1. **用户主动提交的聊天文本：** 用户主动复制后点击悬浮球，或在补充对话页面手动粘贴并标明双方方向，用于提取上下文、生成候选回复。手工补充最多 20 条，默认只在内存中保留最多 60 分钟；此类粘贴文本不证明联系人真实身份。
2. **微信通知（可选）：** 用户单独授予通知读取权限后，可取得系统通知中实际展示的会话名称、文字摘要及时间，不等于微信的完整聊天历史；只有用户主动点击分析，或另行主动开启通知自动分析后，才会作为分析输入。
3. **无障碍服务（可选）：** 用于明确适配的 QQ、X、飞书窗口的可见内容读取及用户主动截图。微信不在无障碍事件监听名单内。无障碍功能不会自动发送聊天消息。
4. **截图和识字：** 只有用户主动选中截图识字，或另行开启其他应用的自动识字功能，才调用系统截图。默认采用手机本地 ML Kit 识字；仅用户显式选择云端识字并配置相应服务时，才将裁剪后的聊天区域图片交给指定服务商。
5. **联系人与自定义信息：** 用户输入的联系人备注、关系、知识库笔记、可选的长期聊天记录，以及最多 500 字的回复风格 Prompt，用于生成更合适的上下文和回复。长期历史和自动整理摘要默认关闭。
6. **接口凭据：** 用户配置的模型服务 API Key 用于直接向该服务商鉴权，存放在应用私有存储中，以 AndroidKeyStore 支持的 AES-GCM 加密保护。应用不会把 API Key 当作聊天正文输出。
7. **运行诊断：** 可记录应用包名、来源类型、消息数量、时间和错误状态，供用户定位故障；不在该诊断记录中保存聊天正文、识字正文、API Key 或完整模型回答。

## 三、数据去向与第三方服务

知言直接由用户手机向所选的判断模型、回复模型、可选视觉模型地址发送相应请求，不通过小书童运营的统一模型代理。发送内容可能包含该轮聊天文本、用户选择的上下文、相关备注或风格 Prompt；首次设置接口时，请阅读所选服务商自己的隐私、保存、训练和收费规则。不同服务商可以分别处理判断、回复及图片。

若用户选择境外服务地址，聊天内容可能传出中国境内。请在使用前确认服务商的数据处理地点与条款；涉及依法需要单独同意或其他跨境处理要求的，应在满足相关条件后使用该服务。默认本地 OCR 不上传图片内容到视觉模型服务商，但 Google ML Kit 可能基于 SDK 服务条款产生性能、使用量或更新检查等网络通信；这些通信与上传用户识字图片和结果不是一回事。

## 四、本地保存、保留与删除

长期聊天历史默认关闭。打开后，所保存的信息留在应用私有存储中，直至用户通过应用内功能删除相关联系人历史、清空知识库，或清除应用数据/卸载应用。风格设置保留至用户修改或恢复默认。临时手动补充的最近对话最多保留 60 分钟，不自动训练个性化模型。Android 应用备份默认关闭。

对已经发送给外部模型服务商的数据，其保存和删除由对应服务商及其服务条款约束，应用本地删除并不意味着外部服务商同步删除。

## 五、用户控制与个人信息权利

用户可在 Android 系统设置中撤销通知、无障碍、悬浮窗或输入法相关授权；可在知言设置中关闭自动分析、长期聊天记录、自动摘要和云端识字，或清理本机联系人资料。候选回复必须由用户确认后自行发送。用户可通过下方联系邮箱提出查询、更正、删除及其他适用法定权利的请求；个人信息处理者将核验请求范围后处理。

## 六、安全、未成年人、更新

知言不包含广告 SDK，也不出售用户聊天数据。重要模型接口须使用 HTTPS（localhost 调试除外），并拒绝自动重定向携带鉴权数据。仍请避免在公共设备、截图或风格 Prompt 中输入敏感密钥、证件号等非必要内容。

本应用暂不以未成年人为专门服务对象；若后续面向儿童推出，应另行评估家长同意和未成年人个人信息保护机制。数据处理范围发生重大变化时，隐私政策应同步更新，并按法律要求重新告知或取得相关同意。
